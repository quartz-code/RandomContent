# Pulse — личный музыкальный плеер

Android-приложение, которое забирает твои лайки из YouTube Music, скачивает их на телефон
и играет офлайн. Без рекламы, подписок, аналитики и интернета во время прослушивания.

## Что умеет

- **Синхронизация лайков в одну кнопку.** Скачиваются только новые треки, с обложками и
  нормальными названиями. Можно включить автосинхронизацию каждые 12 часов и «только Wi‑Fi».
- **Плеер** с очередью, перемешиванием, повтором, управлением из шторки, с экрана блокировки
  и с наушников. Пауза при отключении наушников.
- **Поиск** по названию, исполнителю и альбому, сортировка.
- **Свои плейлисты** внутри приложения.
- **Эквалайзер** с пресетами телефона, ручными полосами и усилением басов.
- Движок yt-dlp обновляется сам раз в сутки (YouTube часто ломает загрузчики, так это чинится без новой версии приложения).

## Установка

1. Открой на телефоне страницу **Releases** этого репозитория и скачай `Pulse-arm64.apk` из последней сборки.
2. Открой файл и разреши установку из этого источника.
3. В приложении: **Синхронизация → Войти через Google → Синхронизировать лайки**.

Новые версии ставятся поверх старой: библиотека и настройки сохраняются.

Если вход через Google внутри приложения не пускает, экспортируй `cookies.txt` с компьютера
(расширение «Get cookies.txt LOCALLY» на открытой music.youtube.com) и нажми
«Импортировать cookies.txt».

## Качество звука

Берётся лучшая аудиодорожка, которую отдаёт YouTube, без перекодирования: обычно Opus ~160 кбит/с,
с Premium-аккаунтом до 256 кбит/с. Lossless у YouTube нет.

## Устройство проекта

| Путь | Что там |
|---|---|
| `app/src/main/java/app/pulse/player/sync/` | вход (cookies), yt-dlp, фоновая синхронизация (WorkManager) |
| `app/src/main/java/app/pulse/player/player/` | сервис воспроизведения (Media3/ExoPlayer), эквалайзер |
| `app/src/main/java/app/pulse/player/data/` | база Room: треки и плейлисты, настройки |
| `app/src/main/java/app/pulse/player/ui/` | экраны на Jetpack Compose |

Сборка локально: `./gradlew assembleRelease` (нужен Android SDK). Каждый push собирает APK в GitHub Actions
и публикует его в Releases.

Файлы хранятся во внутренней памяти приложения и удаляются вместе с ним.
APK подписан ключом `app/pulse.keystore`, который лежит в репозитории, чтобы обновления вставали поверх.
Это нормально для личного приложения, но не публикуй APK как чужое приложение.

Скачивание с YouTube противоречит его правилам использования, так что это только для личного пользования.
