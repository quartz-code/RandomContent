# Pulse — личный клиент YouTube Music

Личная сборка на основе [Metrolist](https://github.com/MetrolistGroup/Metrolist)
(GPL-3.0). Вход в аккаунт, библиотека, лайки, плейлисты, эквалайзер, тексты и скачивание
работают так же, как в Metrolist. Оригинальное описание лежит в `docs/METROLIST_README.md`.

## Что изменено относительно Metrolist

- Своё имя и id приложения (`app.pulse.music`): ставится рядом с официальным Metrolist и не путается с ним.
- **Лайки скачиваются сами.** После каждой синхронизации библиотеки все понравившиеся треки
  (в том числе лайкнутые на компьютере или в другом приложении) скачиваются на телефон.
  Выключается в «Настройки → Плеер → Автоскачивание при лайке».
- **Свой плеер в трёх видах** («Настройки → Внешний вид → Вид плеера»): «Чистый» (по умолчанию),
  «Эфир» в стиле Shortwave со шкалой частот и «Пульт» с крупными кнопками на одной карточке.
  Макеты — в Figma «Pulse — плеер, варианты»; код — `ui/player/PulsePlayer.kt`.
- Нет встроенного обновления до официального Metrolist и Google Cast (сборка `izzy`).
- Одна постоянная подпись: новые версии ставятся поверх старой.

## Установка

1. На телефоне открой **Releases** этого репозитория и скачай `Pulse.apk` из последней сборки.
2. Установи. Старое приложение Pulse (первая версия на yt-dlp) можно удалить, это другое приложение.
3. Войди в аккаунт: «Настройки → Аккаунт → Войти».

Если YouTube у тебя открывается только через VPN, добавь Pulse в список приложений VPN
(или включи VPN для всего телефона), иначе вход и загрузка не заработают.

## Сборка

`./gradlew :app:assembleIzzyRelease` (нужны JDK 21 и Android SDK). Каждый push собирает APK
в GitHub Actions и публикует его в Releases.
